# Devin CLIアダプター

[external-cli.md](external-cli.md)の共通契約に従う。
この参照は起動時の確認点を示す。固定した危険な起動コマンドを標準にしない。

最初にインストール済みCLIで確認する。

```sh
devin --help
```

- 非対話実行、プロンプト入力、出力保存、権限モード、セッション一覧・再開の方法を確認する。
- セッションがcwdに結びつく場合は、IDを明示して区別できるか確認する。区別できなければディレクトリを分けるか逐次実行する。
- ローカル実行かリモート実行かを確認する。リモートなら起点のコード、環境、成果物の回収方法を別途決める。
- sandboxやツール制限が提供されていても、その適用範囲を確認してから利用する。

ユーザーのモデル指定がなければ既定設定を使う。
コミットとGitHub操作は原則として親が行い、実装者には編集と検証の結果を返させる。
