# Codex CLIアダプター

[external-cli.md](external-cli.md)の共通契約に従う。
この参照は起動時の確認点を示す。固定した危険な起動コマンドを標準にしない。

最初にインストール済みCLIで確認する。

```sh
codex exec --help
codex exec resume --help
```

- 親もCodexなら、先に利用可能なネイティブの委譲機能を評価する。
- cwd、sandbox、入力、イベント出力、最終出力を指定する方法を確認する。
- 非対話実行で承認が必要になった場合の挙動を確認し、親が準備する操作と分ける。
- イベント出力を使う場合は、実際のスキーマからsession/thread IDを取得する。
- resumeのオプションがexecと同じとは仮定しない。再開時のcwdと権限を確認する。

ユーザーのモデル指定がなければ既定設定を使う。
コミットとGitHub操作は原則として親が行い、実装者には編集と検証の結果を返させる。
