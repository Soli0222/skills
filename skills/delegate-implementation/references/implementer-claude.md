# Claude CLIアダプター

[external-cli.md](external-cli.md)の共通契約に従う。
この参照は起動時の確認点を示す。固定した危険な起動コマンドを標準にしない。

最初にインストール済みCLIで確認する。

```sh
claude --help
```

- 親もClaudeなら、先に利用可能なネイティブの委譲機能を評価する。
- 非対話実行、session IDの指定・取得、再開、出力形式のオプションを確認する。
- permission modeとツール制限の意味を確認する。deny設定は補助であり、任意のスクリプト経由の操作まで遮断できると仮定しない。
- 作業ディレクトリで実際に適用される設定・規約を確認し、追加で必要なAGENTS.mdなどは指示に明記する。

ユーザーのモデル指定がなければ既定設定を使う。
コミットとGitHub操作は原則として親が行い、実装者には編集と検証の結果を返させる。
